# KVS CPD Certificate Studio

A free, browser-based tool for producing bilingual (Hindi and English) Continuous Professional Development (CPD) certificates in the Kendriya Vidyalaya Sangathan format, at A4 landscape.

**Open the studio:** this repository's GitHub Pages site.

- Keep one master participant list, and tick who attended each course.
- Import courses and participants from CSV.
- Review each batch before export, then download one PDF per course or a ZIP with one PDF per person.
- Everything runs in your browser. No staff data, signatures or templates are uploaded anywhere. Work is autosaved only in your own browser.

`CPC Certificate KVS format.pdf` is the blank certificate format the studio follows.
